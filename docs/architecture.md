# STYLOOM – System Architecture

## Overview

STYLOOM is a proposed digital custom-tailoring platform connecting customers and tailors.

## System Flow

1. Customer opens the STYLOOM website.
2. Customer selects a garment.
3. Customer chooses fabric, colour and design.
4. Customer enters measurements.
5. Customer places a tailoring order.
6. Order information is stored in Firebase.
7. Tailor views and manages the order.
8. Customer tracks the order status.

## Technology Components

- Frontend: HTML, CSS and JavaScript.
- Backend: Firebase services.
- Database: Firebase database service (to be finalised).
- Users: Customers and tailors.

## Note

This is the proposed architecture. It will be updated as the application is developed.
