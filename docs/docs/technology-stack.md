# STYLOOM – Proposed Technology Stack

## 1. Frontend
- HTML – Structure of the website.
- CSS – Styling and responsive design.
- JavaScript – Website functionality and interactions.

## 2. Backend and Database
- Firebase – Proposed backend service and database for storing customer information, measurements and tailoring orders.

## 3. Version Control
- Git and GitHub – Source code management and team collaboration.

## 4. UI Design
- Figma – Designing website layouts and user interfaces.

## 5. Development Plan

The team proposes using these technologies to develop the initial STYLOOM prototype during the 24-hour Hackathon.

**Note:** This technology stack is provisional and may be updated based on the team's final decision and implementation.
